# Haunted Ofrenda

A tiny web page that lights a candle for the ones we remember.

## Setup

1. Install dependencies:

   ```
   npm install
   ```

2. Run the setup script (it prepares the candle assets):

   ```
   bash scripts/summon.sh
   ```

3. Start it and open http://localhost:3000:

   ```
   npm start
   ```
